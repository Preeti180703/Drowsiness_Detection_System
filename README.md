# Project Overview

This project is an AI-powered Drowsiness Detection System developed using Deep Learning, Computer Vision, and Streamlit GUI.
The system detects whether a person inside a vehicle is Awake or Sleeping in real-time from images or videos.
# Features

* Multi-person face detection
* Drowsiness detection (Awake / Sleeping)
* Age prediction
* Image upload support
* Video upload support
* Streamlit GUI
# Technologies Used
* Python
* TensorFlow / Keras
* OpenCV
* DeepFace
* Streamlit
* NumPy
* Matplotlib
* Seaborn
